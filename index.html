🗂 Notes
📖 How to use Notes
📋 Note List
Single clickOpen note in right panel
Double clickRename note title
DragReorder notes
Alt + ↑ / ↓Move the focused note
CheckmarkMark complete / incomplete
🗑 (click twice)Delete note
Type + Enter or +Create new note
📄 Note Detail (right panel)
Click contentEdit section content
Double click titleRename section
Drag sectionReorder sections
Alt + ↑ / ↓Move the focused section header
∧ / ∨ buttonCollapse / expand section
Add buttonAdd new section
Collapse allToggle all sections at once
🔗 Links
Paste URLAuto-fetches page title as link text
[text](url)Write a hyperlink in markdown format
Click linkOpen in new tab
Hover linkShow Open / Edit options

# HeadingH1 heading
## / ###H2 / H3 heading
**text**Bold
*text*Italic
```code```Code block

☀ / 🌙Toggle light / dark theme
Drag dividerResize left / right panels
